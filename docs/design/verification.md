# 首页原型本地验收 · 2026-10-16

范围：`prototypes/homepage/` 三个可切换方向，使用 CQU Moe theme/ui 1.1.0。此记录覆盖本地原型；尚未选择正式方向、配置 CI 或部署生产站点。

## 构建与素材

- `pnpm build`：TypeScript 与 Vite 构建通过。
- `pnpm check:design`：共享设计规则通过。
- 8 个 Logo 文件与设计仓库原素材逐字节一致，SHA-256 见品牌 manifest。
- 单一 ThemeProvider 与 Toaster；首帧主题脚本来自共享 theme 包；业务 CSS 未覆盖 `.ds-*` 内部选择器。

## 浏览器

在 Chromium 中检查三个方向 × 1440 / 768 / 390 / 320px × 浅深主题，共 24 组。另查看桌面、平板和手机截图，并检查 320px 视口。

- 无横向溢出，服务内容和操作完整；每页四项服务、两个内测标记、一个主标题。
- 每页显示三个服务 Logo 和一个 Auth Logo；每枚标识仅显示当前主题对应的素材。Learning CLI 不含图片。
- 手动主题与系统偏好相反时仍正确；刷新保留主题。服务 Logo 为 32×32px，Auth 为 24×24px，无滤镜或变形。
- 索引搜索“雨课堂”只显示 Learning CLI；未命中时有空状态，恢复按钮返回四项；内测筛选返回 QuickLogin 与 Learning CLI。
- 数字键与方向键切换原型，URL 保留选择；输入框中打字、方向键不切换；越界 URL 回落到第一个方向。
- Tab 可到达跳至正文、服务入口、主题和页脚链接；跳转正文有效。减少动态效果时取消选择器滑动。
- 触屏模式下业务操作满足 44px 高度，搜索输入为 16px；无浏览器运行错误。

## 例外与边界

- 页面是公开导航，独立品牌顶栏配合共享 ContentContainer，不使用后台侧栏 AppShell。
- 底部原型选择器原样采用 emil-prototype 的固定样式；28px 按钮属于仅用于比较的开发工具，正式实现时删除。
- 共享 ThemeMenu 的桌面按钮为 36×40px，触屏为 44×44px；本项目沿用共享控件，没有为原型分叉控件。
- 没有验证真实手机、Safari、Firefox、子系统登录后功能或生产部署。服务链接是经项目资料核对的入口，不代表实时健康监测。
